# RBAC-app
How to Run Make sure Python is installed have the code in Vscode or other thing like that.
If using Vscode which I used click the run button in the conner to run it.
It Is a simple app it has
hardcoded usernames and roles.
A simple login check.
Two protected checks
Access checks based on the logged-in user's role
Roles
The app has two roles:
kyle - admin
kole - user.
An unknown username, such as mault, is rejected and it asked you to make and account.
There are to functions Admin and User. Each can access a different system, but they cannot access each other's system.
This app shows Cia Triad: Confidentiality by checking if the user has the right role before showing them access to different information that only a certain role can see like only admin view or only user view. This app can be expanded on to add other things like password and more security like that to make it even more secure so only the right people can see what they have access to.
