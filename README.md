# RBAC-app
It Is a simple app it has
Hardcoded usernames and roles.
A simple login check.
Two protected checks
Access checks based on the logged-in user's role
Roles
The app has two roles:
kyle - admin
kole - user.
An unknown username, such as mault, is rejected and it asked you to make and account.
There are to functions Admin and User. Each can access a different thing but they can not access each others thing.
How to Run Make sure Python is installed.
If using Vscode which i use click the run button to run it
This app shows Cia Triad: Confidentiality by checking if the user has the right role before showing them access to different information that only a certain role can see like only admin view or only user view. This app can be expanded on to add other thing like password and thing like that to make it even more secure so only the right people can see what they have access to.
